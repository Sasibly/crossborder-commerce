## 测试检查

全量 `python -m pytest -o addopts='' -ra --tb=short -p no:cacheprovider`：**851 passed，1 xfailed，1 warning，45.19 秒**。本轮新增 13 项：11 项买家/多商品/售后测试（含参数化场景），2 项备份恢复测试。前一版 commerce 的 9 项测试仍通过。

原有 xfail 仍是规则基线对五星评论中 died 的负面识别缺口，没有把它改成通过；warning 为 TestClient/httpx 弃用提示。

专项覆盖：

- 买家不能访问、取消或退款其他买家的订单，不能使用其他买家的地址。
- 无 CSRF Token 或跨来源写请求被拒绝；登出后旧会话无法使用。
- 多商品任一库存不足时全部回滚；购物车保留。
- 价格和地址修改不影响订单快照；同幂等键重放不会重复建单。
- 整单退款审核前不改变订单状态，批准后按发货状态决定是否回库；拒绝不退款，终态不可反向改写。
- 两商品完成单的预测和记录贡献利润按明细累加，物流按整单记录扣除。
- 未登记退款损失时不输出利润；登记 720 美分净损失后为 -720 美分，重复登记不同金额返回冲突。
- 无 HTTP 请求时，后台任务自动释放过期待支付订单库存，重复清理无副作用。
- 源库 WAL 中已提交数据可备份和恢复；目标存在、源库不存在或损坏时拒绝，失败不留下伪备份。
