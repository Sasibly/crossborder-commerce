# 候选商品指标场景：实现与验收

日期：2026-11-25，Asia/Shanghai。本轮只扩展本地演示系统，供应商、交易执行与成本输入继续按模拟处理。公开统计沿用已核查的版本，本轮没有新增统计来源或宣称再次在线核查。

## 当前完成

工作台可为当前候选 SKU 保存场景输入金额、金额含义、假设说明、指标完整来源及计算结果。POST /v1/commerce/metric-scenarios 必须携带 Idempotency-Key；同租户同键同参数返回原记录，不同参数返回 409。GET 同一路径按 candidate_id 读取本租户场景。

公开 NRF 2025 线上退货销售占比仅计算场景销售额参照。它是美国大型商家的跨品类调查估计，不是本项目 SKU 实测数据，不能作为每件售后成本。模拟单品概率场景明确标注 simulation，输入为每次退货净损失，结果为每件期望损失；只有显式点击采用后才填入决策表单。

服务端再次验证场景属于相同候选与租户、概率口径可用、售后成本与保存结果完全相等。修改成本后保留旧引用会被拒绝；用户可清除引用后使用新的手工假设。保存场景不会自动改写成本、决策、商品或订单。候选切换会清除场景引用；保留下来的金额按手工假设处理。

决策与商品草稿同时保留独立的公开指标参考、模拟售后场景和模拟采购来源。历史读取依赖已保存快照，不通过当前目录重新解释旧值。数据库迁移 0024 新增场景表与不可更新/删除触发器；存在记录后拒绝降级到 0023，避免来源记录丢失。拥有数据库文件控制权的管理员仍能绕过应用保护，不能把这些触发器称为防篡改存证。
