## 一个命令完成部署与验收

在PowerShell中进入项目：

```powershell
cd D:/Codex_Projects/crossborder-commerce
.\local-commerce.cmd deploy
```

这个命令使用现有项目虚拟环境：检查Docker，必要时尝试启动已安装的Docker Desktop；在创建服务前校验所有发布端口必须为loopback；构建镜像、启动到healthy、幂等准备演示数据，然后自动执行配置、HTTP交易、备份恢复和重启持久性验证。已实测完整执行成功，不需要逐步骤确认。

默认采用已在本机验证的Microsoft官方Python基础镜像。首次构建需要可用镜像或镜像仓库连接；不调用真实供应商或支付系统。若现有.venv或Docker尚未安装，先按COMMERCE-README准备依赖；当前机器已具备依赖，无需重复安装。

## 日常命令

```powershell
.\local-commerce.cmd start               # 构建并启动，准备演示数据
.\local-commerce.cmd start --skip-build  # 使用已构建镜像启动
.\local-commerce.cmd status              # 查看健康状态与入口
.\local-commerce.cmd verify              # 对当前部署执行完整验收
.\local-commerce.cmd logs                # 最近60行应用日志
.\local-commerce.cmd stop                # 正常停止，保留命名卷及数据
```

start不会重置已有账号密码或库存。verify会创建虚构买家及两商品测试订单，并完成一次受控容器重启；服务会有短暂中断。停止/启动和重启都已实际验证，原订单、账号、会话及来源快照继续保留。待支付订单仍按原15分钟超时规则处理。

报告默认写入reports/local/，每次使用时间戳和随机后缀，不覆盖旧报告。可用 --report-dir 指定报告目录。本轮两个原始报告保留在docs/evidence/local-runs/。
