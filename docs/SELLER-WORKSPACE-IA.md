# 卖家工作台信息架构调整

适用入口：`http://127.0.0.1:8031/workbench`。本次仅整理卖家前端结构、导航和跨模块定位，不修改业务 API、权限、交易状态、模型预算或数据快照。

## 设计与结构

面向独立站卖家的日常工作，默认先看经营概览，用固定业务导航寻找任务。比较过“单页锚点目录”和“业务分区视图”：前者仍让全部长表单占据一个页面，采用后者。保留同一份 DOM 与表单，通过地址片段切换当前视图，避免切换页面丢失输入、重新提交任务或再次调用模型。

```text
顶栏：CrossBorder · 卖家工作台                         打开买家商城
左侧：日常经营 / 选品与分析 / 管理工具    右侧：分区名称、操作说明
      经营概览                                  分区内快捷入口
      商品与库存                                当前任务表单与列表
      订单与售后
      评论分析
      选品与成本
      经营复盘
      指标来源
      设置与审计
```

沿用产品既有蓝绿视觉：深海蓝 `#16324a` 用于身份和标题、操作蓝 `#226b9b`、证据青 `#087f8c`、工作底色 `#eef3f7`、分隔线 `#cbd8e2`、提醒棕 `#a64519`。标题用系统中文无衬线，正文 Segoe UI / Microsoft YaHei，来源标识用 Consolas。保留品牌但收起大幅介绍，用固定的“候选 → 成本 → 草稿 → 上架”业务路径作为选品区特征，路径链接对应实际任务。界面变化集中于可用空间与定位方式，不加入无关装饰、虚构计数或外部字体依赖。

## 模块与入口

| 一级入口 | 内容与二级入口 | 位置与频率 |
|---|---|---|
| 经营概览 | 高频操作卡片、经营汇总、品类与上架进度 | 默认首页；卡片直达商品、订单、售后、评论分析 |
| 商品与库存 | 商城商品；决策与商品准备 | 左侧日常经营；默认商品列表，草稿入口单独成区 |
| 订单与售后 | 订单查询与履约；买家售后申请 | 左侧日常经营；退款申请不再远离订单 |
| 评论分析 | 保存的评论分析任务及机会；快速离线机会 | 左侧选品与分析；原两种评论入口均保留并解释用途 |
| 选品与成本 | 成本与风险；供应商模拟；报价与压力比较；场景测算 | 工作区顶部共享唯一候选选择器；各步骤有本地快捷入口 |
| 经营复盘 | 预测与经营结果 | 左侧选品与分析，保留原比较口径 |
| 指标来源 | 公开统计与模拟假设的来源明细 | 左侧管理工具；场景测算中可跳转查来源 |
| 设置与审计 | 访问设置；订单支付费假设；一致性检查；操作审计 | 左侧管理工具；低频和仅 owner 可操作项目集中 |

导航使用真实链接，支持 URL 直接定位、刷新和浏览器前进/后退。分区内跳转滚动并聚焦目标标题，当前一级导航标记 `aria-current`；未知地址回退概览。小屏将侧栏改为顶部常驻折叠菜单，保留各业务和原有其他工具入口。默认无 JS 时显示功能结构，有 JS 后加载业务数据并仅显示一个分区。

商品区新增名称 / SKU / 品类关键词搜索、商品状态和品类组合筛选，展示匹配数量及已上架总数。默认全部商品，明确 draft 同时用于草稿和已下架记录；筛选不改变商品状态、库存或 API 查询逻辑。切换分区和刷新业务数据保留筛选条件。

跨区协作：创建候选 → 选品成本；采用售后场景或比较情景 → 成本表单；保存决策 → 商品准备；概览品类进度中的“查看该品类” → 快速离线机会。切换仅改变可见区域，不触发请求、清空表单或修改业务对象。

实际浏览器检查发现并修复旧初始化与直达链接的冲突：`?category=pet_fountain#orders/buyer-refunds` 现在同时保留评论品类和订单售后定位；异步初始加载完成后重新校正子区滚动位置，不再被自动带回评论区。

## 验证口径

- 原表单控件 ID、提交函数和 API 请求不变，所有功能均归入唯一分区；不克隆候选选择器。
- 导航切换、直达子区、前后退、未知路由回退、键盘焦点和小屏菜单可用；隐藏区不可进入 Tab 顺序。
- viewer 仍能使用导航；操作按钮继续采用原角色限制。
- 验证评论缓存/模式限制、商品与订单原有回归；不额外调用外部模型。
- 部署前后比较工作库业务记录，保留原商城商品、订单、分析历史和两个已用尽授权。
- 历史 1—5 验收不改写为本次结果。

## 实际验收结果

2026-11-26 已部署至本机8031，schema26，健康检查通过。全量隔离测试 **1054 passed、1 known xfailed、1 warning**；新增3项页面结构、路由/权限/输入保留及组合筛选回归测试。已知预期失败仍是原V1隐性负向词表缺口，warning为原Starlette/httpx弃用提示。

浏览器工具初始化受本机 kernel assets 路径缺失影响，改用已安装 Chrome 的独立临时配置目录与无头模式完成真实页面检查，未安装新依赖、使用用户浏览器会话或提交业务表单。1440×1000与390×844下，八模块切换、前后退、直达刷新、焦点、筛选、未提交内容保留及小屏菜单通过；页面无横向溢出。买家商城仍能展示商品，匿名账户查询的预期401单列，不计为卖家页面错误。

部署前后数据库全表内容摘要一致，原商品/订单/分析/审计均保留；业务一致性无异常。冻结16个来源与规则文件不变，未新增真实模型请求，两份授权累计仍为40次。
